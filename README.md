# Bus Coin — Turismo Toscano

App de entretenimiento para pasajeros de micros de larga distancia, para
Turismo Toscano. Copia de [Bus Coin](https://github.com/Jean-Alessi/bus-coin)
con su propia marca — comparte el mismo proyecto de Firebase, aislado por
agencia (ver `ONBOARDING.md`).

## Contenido

- `index.html` — prototipo autocontenido (HTML + CSS + JS) que simula la app dentro de un mockup de celular. Se abre directo en el navegador, sin build ni dependencias.

## Cómo verlo

Abrí `index.html` en cualquier navegador.
